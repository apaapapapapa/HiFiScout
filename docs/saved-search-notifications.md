# 保存検索の新着・値下げ通知

「保存した検索」を開き、対象の「新着・値下げを通知」から希望価格と通知種類を選び、通知を有効にします。ブラウザーの通知許可が必要です。iPhone／iPadではホーム画面に追加したHiFiScoutから設定します。メール登録やアカウント作成は不要です。

## 対象と停止

- 保存検索の条件を使い、在庫ありの出品だけを対象にします。希望価格と元の上限価格が両方ある場合は低い方を適用します。店舗・価格・状態などは同じ出品で一致する必要があります。
- 有効化・条件変更後の初回観測または価格履歴上の値下げが対象です。最初から既存商品を一括通知しません。通知時の価格は収集時点の情報で、在庫・販売価格は販売店で確認してください。
- 通常は収集後15分間隔で確認し、ページと条件を分割して処理します。収集の頻度・夜間停止は変えません。バックログ、予算上限、OSの制限や通信障害で遅延・未配信が生じます。即時配信やすべての変更の捕捉は保証しません。
- 各検索の「通知を解除」、または「この端末の通知をすべて停止」で停止できます。通知中、または通知状態が未確認の保存検索は、サーバー側の解除が確認できてから削除します。通知なしと確認済みの保存検索は通信障害時も端末内で削除できます。端末内データを消す前に停止してください。
- 1端末5条件まで、通知設定は90日間です。有効化・更新で延長します。お気に入りの希望価格は自動送信しません。通知ごとに希望価格を指定してください。

## 保存する情報

明示的な有効化時だけ、検索条件・希望価格・通知先URLと暗号化公開鍵を保存します。検索名、検討メモ、お気に入り一覧は送信しません。通知先と検索条件はAPIキャッシュ・ログに載せません。通知管理用のランダムなトークンはこのブラウザーに保存し、サーバーではハッシュで所有を確認します。他端末との同期・トークンの復旧機能はありません。

通知本文はWeb Push標準で暗号化します。VAPID秘密鍵は専用Durable Object内で生成・保持し、公開APIは公開鍵だけを返します。停止時は対象の設定と配信記録を削除し、全停止では通知先も削除します。成功・失敗した通知本文は消去し、重複抑制の記録は7日で期限切れになります。期限切れ情報は各処理で件数を区切って削除するため、物理削除が遅れる場合があります。

## 運用と負荷

`NotificationHub`は既存の巡回・Queue・D1書込から独立したSQLite Durable Objectです。新しいD1テーブルや巡回は追加しません。`NOTIFICATIONS_ENABLED=false`でAPIと次回以降のAlarm処理を停止できます。再開後は通知設定の有効化・更新がAlarmを再設定します。

| 境界 | 初期上限 |
| --- | --- |
| 通知先／全条件 | 50端末／100条件 |
| 1回の候補／条件照合／送信 | 20出品／5種類の検索／3件 |
| 1日（UTC）のD1文数／読込／送信試行 | 2,000文／200,000行／500回 |
| 配信記録／保存期間／再試行 | 10,000件／7日／合計3回 |

日次予算はI/O前に永続化し、失敗したD1照会には5,000行分を留保します。成功時のD1ネイティブメタデータで精算し、メタデータ不明時はその日の追加照会を停止します。単一照会の実読込が留保を超える可能性はあるため、これはアカウントの課金上限の保証ではありません。SQLite、CPU、Alarm、Push通信はD1予算とは別です。

候補は`last_changed_at`の既存インデックスから取得し、2分の反映待ちと1時間の重複確認を設けます。検索投影の反映が重複確認の範囲より遅れた変更や、複数の値下げが次回確認前に上書きされた場合は捕捉できないことがあります。商品名・在庫だけの更新を新しい値下げとして扱いません。

配信前に試行数を記録し、`429`／一時障害では`Retry-After`を尊重します。`404`／`410`で失効した通知先を削除します。配信確認応答が失われた場合の完全な一度限り配信は保証できませんが、配信IDとブラウザーの通知タグで重複を抑制します。保存検索画面には最終確認完了・遅延・配信失敗を表示します。

実D1とSQLiteの初期負荷は`test/notification-query.test.ts`、`test/notification-runtime.test.ts`で測定し、`scripts/harness/load-contracts.ts`で既存負荷と一緒に検査します。ブラウザー操作・暗号化・配信状態のテストは実端末への到達率を証明するものではありません。上限拡大は実利用と本番メトリクスを確認してから判断します。
