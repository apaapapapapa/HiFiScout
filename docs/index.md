# HiFiScout Developer Guide

This site combines curated architecture documentation with references generated directly from the current implementation.

## Generated references

- [Source API](./reference/api/) is generated from exported TypeScript symbols and JSDoc comments with TypeDoc and `typedoc-vitepress-theme`.
- [HTTP API](./reference/http-api.md) is generated from executable route contracts as OpenAPI 3.1 and rendered with Redocly.
- [Module dependency graph](./architecture/dependencies.md) is generated from ES module imports with dependency-cruiser.
- [Database schema](./database/index.md) is generated by applying all D1 migrations locally and analyzing the resulting SQLite schema with SchemaSpy.

## Architecture

- [Data platform architecture](./data-platform-architecture.md) documents D1/FTS5 search, Product Identity Resolution, the R2 Evidence Archive, observability, and the PostgreSQL exit boundary.
- [Module dependencies](./architecture/dependencies.md) shows the current source-level dependency graph and explains the architecture check enforced in CI.

## Source of truth

Generated documentation is intentionally not committed. Route contracts, source code, JSDoc comments, imports, and `migrations/*.sql` remain the source of truth. CI regenerates the developer site and publishes it as a workflow artifact on every pull request and every push to `main`.
