The screenshots show factual listing summaries rendered by HiFiScout, without seller photos,
logos, descriptions or staff comments. They are historical UI examples, not current offers.
No product records or production settings were changed for the captures.

To refresh, open the public search, select card view, dismiss search suggestions, then capture
the search controls and first row of results. Open a product with multiple offers and capture
its comparison table after loading completes. Keep visible prices and status messages intact;
do not manufacture a healthy sync state or current stock. Update the capture date, links and
alt text in this file and the root README together. Keep images local and small enough for the
README to load promptly; do not hotlink seller images or include admin screens.
